# Apple-Style Portfolio 🍎

A sleek, modern portfolio website inspired by Apple's minimalist design philosophy. Built with pure HTML, CSS, and JavaScript.

## ✨ Features

- **Minimalist Design**: Clean, Apple-inspired aesthetic with smooth animations
- **Fully Responsive**: Works seamlessly on all devices from mobile to desktop
- **Smooth Scrolling**: Elegant navigation with smooth scroll behavior
- **Interactive Animations**: Fade-in effects on scroll for engaging user experience
- **Modern CSS**: Uses CSS Grid, Flexbox, and custom properties
- **No Dependencies**: Pure vanilla JavaScript - no frameworks required

## 🎨 Design Highlights

- Glassmorphism navbar with backdrop blur
- Gradient hero section
- Card-based project showcases
- Clean typography using system fonts
- Responsive navigation
- Interactive hover effects

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/KrAzad0/apple-style-portfolio.git
```

2. Navigate to the project directory:
```bash
cd apple-style-portfolio
```

3. Open `index.html` in your browser:
```bash
open index.html
```

Or use a local server:
```bash
python -m http.server 8000
```

## 💡 Customization

To customize this portfolio for your own use:

1. **Update content in `index.html`**:
   - Change name, titles, and descriptions
   - Update project information
   - Modify skills lists
   - Add your contact links

2. **Adjust colors in `styles.css`**:
   - Modify CSS custom properties in `:root`
   - Change gradient colors
   - Update accent colors

3. **Add more sections**:
   - Follow the existing HTML structure
   - Add corresponding styles
   - Update navigation links
